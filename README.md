# Christoffel-s-Menu
The Christoffel's Menu App is an app designed for a chef to add menu items and view them in live-updating lists. Its much easy to use ,unlike a peace of paper, you don't have to rip a piece of paper when making a mistake just cancel and type the correct staff.

# The Features of the app
*The Home screen with a flat List of all menu items and an empty-list.
*An Add Item screen with dish name, description , course (Picker) and Price.
*Validation with error message for required fields and invalid prices.
*Success confirmation after saving a dish.
*List updates automatically when a new item is added.
